# 🛍️ ShopMate — Full Stack E-Commerce App

A production-ready e-commerce application built with React, Node.js, MongoDB.

## 🚀 Features
- 🛒 Product listing with search & category filters
- 🔐 JWT Authentication (Register/Login)
- 💳 Razorpay Payment Integration
- 👑 Admin Panel (Products, Orders, Users)
- 💬 Real-time Support Chat (Socket.io)
- ❤️ Wishlist & Cart Management
- 📦 Order History & Tracking

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Context API
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Atlas)
- **Payment:** Razorpay
- **Real-time:** Socket.io
- **Auth:** JWT + bcrypt

## ⚙️ Setup

### Backend
cd server
npm install
# Add .env file with MONGO_URI, JWT_SECRET, RAZORPAY keys
npm start

### Frontend
cd client
npm install
npm start
